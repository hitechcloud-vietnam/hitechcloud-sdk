# HiTechCloud SDK Agents

AI agent configurations for using the HiTechCloud SDK.

## Available Agents

- [service-manager](service-manager.md) — Manage HiTechCloud services
- [billing-agent](billing-agent.md) — Handle billing and invoices
- [dns-agent](dns-agent.md) — Manage DNS zones and records
- [domain-agent](domain-agent.md) — Domain registration and management

## Usage

These agent configurations can be used with:
- OpenAI Assistants API
- Anthropic Claude
- Any LLM that supports tool use
